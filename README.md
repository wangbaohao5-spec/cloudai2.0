# Vahoro

Vahoro 是 AI 电商商品上架内容工作台，围绕一个商品完成分析、策划、上架文案、商品图片、详情页与素材整理。

## Development

```bash
pnpm install --frozen-lockfile
pnpm dev
```

项目使用 Node.js 24 和 pnpm 11.20.0。数据库结构由 Prisma 管理；日常构建不会自动执行 migration。
